# EP09 外部集成、自定义命令与链接

> 目标：让 GitSpace 不内置的能力也能一步到达：在终端和编辑器中打开、卡片号与提交链接、可批量执行的自定义命令。

## 1. 现状

- 只有「在访达显示」（仓库行右键、多仓状态表）与「打开日志目录」；没有在终端、编辑器、浏览器打开的入口。
- 卡片号只在变更集与聚合检索中用正则提取分组，不渲染为链接。
- 没有自定义命令。

## 2. 对标参考

- Fork：Open in 多种终端（Ghostty、Kitty 等）与编辑器（Xcode、VS Code、Zed、Antigravity），在 Xcode、BBEdit 中定位到行；标签右键「在终端打开」；Custom commands 支持 bash 命令、URL 命令、带界面的命令（文本框、分支下拉、文件选择、复选框），可与团队共享；issue tracker 规则在 worktree 间共享（2.71）。
- IDEA：Issue Navigation 用「正则 → URL」把提交信息中的单号变为链接。

## 4. 交互规格

### 4.1 Open in（F01、F02）

- 入口：仓库行、标签页、文件行、提交详情文件列表的右键「在终端打开 / 在编辑器打开 / 复制路径」；工具栏「打开于 [v]」按钮记住上次选择。
- 设置中列出已安装的终端与编辑器，可添加自定义命令行；文件定位到行使用各编辑器自己的参数（如 `xed --line`、`code --goto file:line`）。

### 4.2 卡片号与 Web 链接（F03、F04）

| 设置项 | 示例 |
|---|---|
| 卡片号正则 | `TASK-\d+`（以团队实际编号规则为准，MRD §17.4） |
| 卡片 URL 模板 | `https://<icafe 域名>/issue/$0/show`（`$0` 为整段匹配） |
| 提交 URL 模板 | `https://<host>/<repo>/commit/{sha}`，按 remote 主机分别配置 |

- 提交信息中的匹配项显示为链接，点击用默认浏览器打开；右键「复制链接」。
- 模板随工作区导出（EP01-F08），团队内只需配置一次。

### 4.3 自定义命令（F05）

```text
+-- 编辑自定义命令 ------------------------------------------------------+
| 名称      [同步 Pods 并构建                                       ]    |
| 作用域    (*) 仓库   ( ) 工作区   ( ) 提交   ( ) 文件   ( ) 分支         |
| 命令      [pod install && xcodebuild -scheme "$GS_INPUT_SCHEME"   ]    |
| 输入项    + 文本框  SCHEME   默认值 [GdThread]                         |
| 执行方式  (*) 后台执行并显示输出   ( ) 在终端中打开执行                 |
| [x] 允许对多个仓库批量执行（并发沿用批量设置）                          |
+-----------------------------------------------------------------------+
| 可用变量：$GS_REPO_PATH  $GS_REPO_NAME  $GS_BRANCH  $GS_UPSTREAM        |
|           $GS_SHA  $GS_FILE  $GS_CARD                                  |
+-----------------------------------------------------------------------+
```

- 入口：命令面板、对应作用域的右键菜单、菜单栏「命令」。
- 批量执行走 EP05-F01 的流程，逐仓显示输出与返回码。
- 变量以环境变量传入命令，不做字符串拼接，避免路径或分支名中的特殊字符被 shell 解释。

| 安全规则 | 说明 |
|---|---|
| 首次执行确认 | 展示展开后的完整命令与作用的仓库，确认后才执行；之后命令内容变更时再次确认 |
| 共享命令需信任 | 从导入的工作区带来的命令默认「未信任」，逐条确认后才可运行 |
| 全部记录 | 每次执行写入 JSONL 操作日志：命令、仓库、返回码、耗时 |
| 不经安全闸 | 自定义命令以用户身份执行，不受引擎参数白名单约束，确认框写明这一点 |
| 不预置危险命令 | 内置示例不包含 force push、`reset --hard`、`clean` |

### 4.4 AI 代理设置（F06）

- 配置项：可执行文件路径、参数模板（输入从 stdin 传入）、超时、用途开关（提交信息草稿）。
- 开启时展示一次说明：哪些数据（暂存区 diff、分支名）会交给该工具，数据去向由该工具决定。
- 不保存 API key，不内置云端服务。

## 5. 验收口径

1. 在终端打开时，终端的工作目录等于仓库路径；在编辑器打开文件时定位到选中行。
2. 卡片号链接的匹配与设置的正则一致，URL 替换结果正确。
3. 自定义命令在路径含空格、分支名含 `/` 与引号时执行结果正确，没有 shell 注入。
4. 批量执行的逐仓返回码与输出与逐仓手动执行一致。
5. 未信任的共享命令无法执行；首次执行一定出现确认。

## 6. 风险与明确不做

- 不做托管平台账号登录与通知（MRD 无账号体系）；Web 链接只拼 URL，不调用平台接口。
- 自定义命令绕过引擎安全闸，因此确认与日志是必选项，不提供「永不确认」的全局开关。
