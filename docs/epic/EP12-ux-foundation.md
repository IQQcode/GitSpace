## 4. 交互规格

### 4.1 中英双语（F05）

- 所有界面文案进入 String Catalog；设置中切换语言。
- git 原始输出（stderr、钩子输出）不翻译，原样展示。

### 4.2 索引与自动刷新（F06、F10）

- 索引是派生数据，可随时删除重建（TechStack §6.1）；设置中提供「重建索引」，状态栏在灌库时显示「索引中 12 / 52」。
- 灌库在后台进行，已就绪的仓先显示（MRD 10.6 流程一）。fetch、commit、merge 后只对受影响的仓做增量灌库。
- 自动刷新：工作区根目录一条 FSEventStream，排除 `build/`、`DerivedData/`、`Pods/`、`node_modules/`，500ms 去抖，只刷新受影响的仓；另有 30s 轮询 `git status` 兜底；窗口重新激活时刷新可见仓。
- 后台 fetch 默认关闭（50 仓定时 fetch 会给自建远端带来压力），开启后间隔可设，状态区标注「数据截至 X 分钟前」（MRD 10.4-3）。

### 4.3 操作历史与可撤销通知（F11）

```text
+-- 操作历史 ---------------------------------------- [仓库 v] [结果 v] [搜索      ] --+
| 10:42:03  GdThread        push          成功   1.2s                                  |
| 10:41:50  GdHome          branch.delete 成功   0.1s   [恢复分支]                      |
| 10:40:12  GdFeedSupports  pull.ff-only  失败   60s    超时  [重试] [复制命令]          |
+-------------------------------------------------------------------------------------+
```

- 数据来自现有 JSONL 操作日志；每条可展开查看参数（不含凭据）与 stderr。
- 可撤销动作与恢复方式：删分支 → `git branch <name> <sha>`；drop stash → `git stash store <sha>`（使用 git 输出中的 stash SHA）；删 tag → 在原 SHA 重建；丢弃改动 → EP04-F01 快照。

## 5. 验收口径

1. 切换为英文后界面没有残留的中文文案（git 原始输出除外）。
2. 50 仓 × 10 万提交数据集下：首屏 ≤3s、过滤 ≤300ms、滚动 ≥55fps、常驻内存 ≤500MB；冷启动 ≤2s（MRD 10.4-2、10.4-6）。
3. 自动刷新后的状态与 `git status --porcelain`、`git rev-list --count` 一致（MRD 10.4-3）；只读刷新前后工作区不变（MRD 10.4-4）。
