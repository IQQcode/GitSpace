# GitSpace 功能与交互 v1.0

记录 GitSpace macOS 客户端**当前已落地**的功能与交互，供产品 / 研发 / 新人快速了解形态。实现见 `repos/GitSpace`，设计来源见 `design/gitspace-prototype/index-origin.html` 与 `specs/`。本文档随功能演进更新，不替代 MRD（需求）与 TechStack（技术）。

状态：对应 MVP + Story-1030（界面对齐原型），构建与单测通过，可视化由人确认。

## 1. 概述

GitSpace 是面向多仓库（50+ 组件仓）日常 Git 操作的 macOS 原生客户端：跨仓统一时间线、批量同步、逐仓提交与分支合并。所有 Git 数据来自系统 git CLI，本地运行不上传。

## 2. 全局框架

窗口自上而下：顶部标题栏 + 主体（左侧栏 + 主区）+ 底部状态栏。

- 顶部标题栏：品牌、工作区切换、快速操作、主题、设置
- 左侧栏：工作区卡片 + 仓库筛选 + 仓库列表 + 底部纳管与操作入口
- 主区：顶部 5 个视图 tab + 视图内容；任意仓库合并进行中时，主区顶部常驻横幅
- 底部状态栏：纳管仓数、未推送提交数、上次刷新时间、本地模式标识、git 版本、应用版本

## 3. 顶部标题栏

- 品牌：GitSpace 标识
- 工作区 pill：显示当前工作区名与仓库数（当前为单工作区，下拉为占位）
- 快速操作：点击或 ⌘K 打开命令面板
- 主题：在 跟随系统 / 浅色 / 深色 间循环切换（⌘⇧L）
- 设置：打开设置窗口（批量并发度、时间线加载窗口、外观、操作日志目录）

## 4. 左侧栏

- 工作区卡片：工作区名 + MULTI-REPO 标识、仓库构成摘要、仓库数与 git 版本、数据新鲜度（数据截至 X）、刷新时的加载进度条
- 仓库筛选：按仓库名或分支名实时过滤列表
- 仓库列表：每行显示色点、仓库名、分支名与同步状态徽标（●n 未提交 / ↑n 领先 / ↓n 落后 / ✓ 干净 / 冲突 / 读取失败）；右键可在访达显示或从工作区移除
- 底部入口：添加仓库（⌘O）、扫描父目录（⌘⇧O）、导入 mgit 清单、Stash 暂存（⌘⇧S）、Tag 管理（⌘⇧T）

## 5. 主区五视图

### 5.1 统一时间线

跨仓合并提交图：过滤条（仓库 / 分支 / 作者 / 时间 / 关键字）+ 左侧提交列表（图列、作者、短 SHA、相对时间）+ 右侧提交详情（文件级 diff，可复制完整 SHA）。超大仓按时间窗口截断并在底部提示。

### 5.2 提交

针对左侧选中仓库：未暂存 / 已暂存两栏，文件级与块级（hunk）暂存，丢弃改动（二次确认），填写提交信息并提交，支持 amend，pre-commit 钩子失败原样透出。

### 5.3 多仓状态

状态体检表：各仓同步状态与数据新鲜度，底部浮动条执行批量 Fetch / Pull / Push。批量流程逐仓 排队 / 执行 / 成功 / 跳过 / 失败，可取消、重试失败项；Pull 默认 ff-only。

### 5.4 变更集（P1/P2 超前占位，待评审）

按卡片号跨仓聚合提交：左侧卡片列表（卡片号、涉及仓色点、涉及 N 仓 / 提交数 / 作者数 / 最新时间），右侧该卡片下各仓提交，可复制交付清单或跳转时间线按卡片号过滤。卡片号从提交信息正则提取。

### 5.5 聚合检索（P1 超前占位，待评审）

按关键字（卡片号 / 提交信息 / 作者）跨全部仓库检索，结果按仓库分组，可一键生成 CR 清单到剪贴板。

## 6. 命令面板（⌘K）

弹层输入命令，支持输入过滤、上下键选择、回车执行、Esc 关闭。命令含：切换主题、全部仓库 Fetch、批量 Pull / Push（自动选中待同步 / 未推送仓）、新建管理分支、合并分支、打开 Stash、打开 Tag、添加仓库、扫描父目录、导入 mgit 清单。分支 / 合并 / Stash / Tag 命令作用于当前选中仓库，未选中时提示先选。

## 7. 弹窗

- 添加仓库：输入或浏览本地路径纳管
- 扫描父目录：发现目录下所有 Git 仓库（深度 3，跳过构建产物），批量勾选纳管
- 导入 mgit 清单：粘贴多行仓库路径批量纳管
- 批量执行：逐仓进度与结果，可取消 / 重试
- 分支：本地与远程分支列表，新建并切换、切换（脏工作区引导 stash 后切换）、重命名、删除（已合并 -d / 未合并 -D 强确认）、检出远程分支
- 合并：选来源分支 + no-ff 开关合并；冲突列表 取当前 / 取对方 / 生成合并标记 / 标记已解决，全部解决才可完成合并提交，可随时中止
- Stash：保存（带描述）、列表、Pop / Apply / Drop（二次确认）
- Tag：创建（轻量 / 附注）、列表、删除（二次确认）

## 8. 全局行为

- 数据来源：Git 状态一律来自系统 git CLI 输出，不自算
- 安全边界：永不 force push；删分支 / Drop stash / 删 tag / 中止合并等破坏性操作二次确认；写操作记入本地 JSONL 日志
- 主题：浅色 / 深色 / 跟随系统，经令牌层统一；尊重系统减少透明度与增强对比度
- 本地模式：数据不上传，底部状态栏常驻标识

## 9. 快捷键

- ⌘K 命令面板，⌘⇧L 切换主题（均在应用菜单常驻注册）
- ⌘O 添加仓库，⌘⇧O 扫描父目录，⌘⇧S Stash，⌘⇧T Tag，⌘⇧B 分支，⌘⇧M 合并，⌘⇧F 全部 Fetch（经命令面板触发执行）
