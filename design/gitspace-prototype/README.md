# GitSpace 多仓库 Git 客户端原型

## 运行方式
直接用 Chrome / Edge / Safari 打开 `index.html`，无需安装依赖、无需构建。建议窗口宽度 ≥1280。

## 文件说明
- `index.html`：**完善版交互视觉稿 v2**（本目录唯一维护入口）
- `index-origin.html`：v1 原始原型存档，仅作对照，不再维护

数据为原型演示用示例数据，所有 Git 操作均在前端模拟，不会访问真实仓库。演示状态可通过命令面板（⌘K → 重置演示数据）随时复位。

## 视觉规范
- 亮 / 暗双主题：仅覆盖 CSS token（右上角切换或 ⌘⇧L），组件样式不随主题重复
- Token 化：8pt 间距、固定字号阶梯、单主色 + 语义色、统一圆角 / 动效时长 / z-index 层级
- 可访问性：focus-visible 焦点环、图标按钮 aria-label、弹窗 role=dialog、Toast aria-live、尊重 prefers-reduced-motion

## 视图与交互（对照 MRD v1.5 P0 闭环）
| 视图 | 覆盖能力 |
|---|---|
| 统一时间线 | 跨仓合并提交图；仓库 / 分支 / 作者 / 时间 / 关键字筛选；提交详情（统一 / 并排 diff、Blame）；骨架加载、筛选空态、单仓读取失败可重试 |
| 提交 | 未暂存 / 已暂存两栏；文件级 + 块级暂存；丢弃改动（单块 / 单文件 / 全部，二次确认）；提交信息历史、amend、pre-commit 钩子失败演示；工作区干净态 |
| 多仓状态 | 状态体检表（排序 / 数据新鲜度）；批量 Fetch / Pull / Push：预检（逐仓跳过原因）→ Push 推送确认（仓库数 / 提交数）→ 逐仓排队 / 执行 / 成功 / 跳过 / 失败，支持取消、单仓重试、重跑失败项；Pull 双模式（ff-only 默认 / 常规合并） |
| 变更集（P1） | 按卡片号跨仓聚合，缺口仓库提示、复制交付清单、跳转时间线 |
| 聚合检索（P1） | 卡片号跨仓检索、按仓库分组结果、生成 CR 清单 |

## 全局交互
- **合并冲突流**：合并分支弹窗（快进优先 / 常规合并）→ 全局「合并进行中」横幅 → 冲突面板（取当前 / 取对方 / 两者保留 / 外部工具，全部解决后才可提交合并，可随时中止）
- **分支管理**（⌘⇧B）：本地 / 远程分支列表、新建 / 切换 / 重命名 / 删除、检出远程分支；脏工作区切换被阻塞时引导 Stash
- **Stash**（⌘⇧S）：保存 / Pop / Apply / Drop（丢弃需确认）
- **Tag**（⌘⇧T）：轻量 / 附注标签创建、删除、推送
- **命令面板**（⌘K）：全部高频操作键盘直达；**设置**：批量并发度、外部合并工具、匿名统计开关
- 批量 Pull 遇分叉：ff-only 跳过并提示；常规合并进入冲突流；Push 非快进被拒不自动合并、永不 force
